# Revenue Execution content images

Public website images for Revenue Execution resources live in this folder.

The master/source version of every approved content image is stored in the Revenue Execution / Content Images Google Drive folder.

## Standard formats

Use the same approved hook and visual idea across channels.

- LinkedIn feed: `1080 x 1350` (4:5) — default social format
- Website article hero: `1600 x 900` (16:9) — default website format
- Square: `1080 x 1080` — only when specifically useful

## Locked visual structure

Each hook image should normally contain:

1. Small topic label
2. One strong hook — ideally 6–12 words
3. Optional short supporting line
4. Revenue Execution branding
5. One simple visual device only when it helps explain the point

The image is the scroll-stopper. The LinkedIn post or article does the explaining. Avoid putting the whole argument into the image.

## Naming convention

Use the content ID first so every image can be traced back to the Content Pipeline.

- `RE-###-website-hero.<ext>` — wide website article hero
- `RE-###-linkedin-4x5.<ext>` — LinkedIn feed image
- `RE-###-square.<ext>` — optional square variant
- `RE-###-<short-topic>.<ext>` — framework/diagram variant when needed

Examples:

- `RE-002-website-hero.svg`
- `RE-002-linkedin-4x5.png`

## Workflow

1. Idea is entered in the Content Pipeline.
2. Article and LinkedIn copy are drafted and approved.
3. Hook is approved.
4. LinkedIn 4:5 and website 16:9 images are created from the same visual concept.
5. Master/source images are stored in Revenue Execution / Content Images on Google Drive.
6. Website-ready image is added here and linked from the article/resources page.
7. LinkedIn-ready image is attached directly to the LinkedIn post.
8. Live URLs and performance are written back to the Content Pipeline.

Keep images tied to a content ID. Do not create decorative images without a publishing purpose.
